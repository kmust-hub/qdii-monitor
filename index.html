邮箱订阅

当基金的申购/赎回状态或单日限购额度发生变化时，自动向你的邮箱发送提醒。

如何真正开启邮件提醒？（需要后端配置）

网页本身是静态页面、无法直接发邮件。邮件由 collect.py 在本地或定时任务运行时发送： 把下面的 config.json 保存到项目根目录，填入你的 SMTP 账号，再重新运行 collect.py 即可。 使用 GitHub Actions 时，可在仓库 Settings → Secrets and variables → Actions 中配置 SMTP_HOST、SMTP_PORT、SMTP_USER、SMTP_PASSWORD、SMTP_SECURITY、NOTIFY_EMAILS。
